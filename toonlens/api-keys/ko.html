툰렌즈 API 키 받는 법

최종 수정: 2026-11-01. 업체별 순서는 각 업체의 공식 문서(2026-11-01 확인)를 따릅니다. 업체 화면과 요금은 바뀔 수 있습니다. 요금은 각 업체 페이지에서 확인하세요.

툰렌즈의 3·4단계(클라우드 AI) 번역은 사용자 본인의 API 키로 업체에 직접 요청합니다. 개발자는 키와 번역 내용을 받지 않습니다. 요금은 키를 만든 계정에 매겨집니다.

키를 지키세요. 키를 남에게 보이거나 메일·채팅·스크린샷으로 보내지 마세요. 키가 새면 남이 내 계정으로 요금을 쓸 수 있습니다. 키가 샜다고 생각하면 업체 페이지에서 그 키를 바로 지우고 새로 만드세요.

툰렌즈에 키를 넣는 법 (모든 업체 같음)

  1. 업체 페이지에서 키를 만들고 복사합니다 (아래 업체별 순서).
  2. 툰렌즈에서 설정(오른쪽 위 톱니)을 엽니다. 맨 위 "번역 모드"에서 3단계 또는 4단계 카드를 누릅니다 (그림 ①).
  1. "클라우드 연결" 창에서 업체를 고릅니다 (그림 ②).
  2. 키를 아직 만들지 않았으면 "키 받는 법 보기"를 누릅니다 (그림 ③). 이 페이지의 그 업체 칸이 열립니다.
  1. 창을 위로 밀어 "API 키" 칸을 길게 누르고 붙여 넣습니다 (그림 ④). 키는 점으로 가려져 보입니다.
  2. 모델은 기본값(첫 줄)을 그대로 두어도 됩니다 (그림 ⑤).
  3. 외부 전송 안내를 읽고 동의하고 사용을 누릅니다 (그림 ⑥). 키를 넣어야 이 단추가 켜집니다.

키는 기기 안에 암호화해 저장합니다. 저장한 뒤에는 칸에 다시 보이지 않습니다. 키를 바꾸려면 같은 창에서 새 키를 붙여 넣습니다.

Google Gemini

키 받는 곳: aistudio.google.com/apikey · 공식 안내: Gemini API 키

  1. Google AI Studio(aistudio.google.com/apikey)에 Google 계정으로 들어갑니다.
  2. 처음이면 서비스 약관에 동의합니다. 약관에 동의하면 기본 프로젝트가 만들어집니다.
  3. API Keys 화면에서 Create API key를 누릅니다.
  4. 프로젝트를 고르라고 하면 기본 프로젝트를 고릅니다.
  5. 만들어진 키를 복사합니다.

키는 Google Cloud 프로젝트에 속합니다. 무료 사용량과 요금은 Google의 Gemini API 요금 페이지를 보세요. 무료 사용량으로 보낸 내용은 Google이 서비스 개선에 쓸 수 있습니다.

Anthropic Claude

키 받는 곳: platform.claude.com → Settings → API keys · 공식 안내: Get your Claude API key

  1. Claude Console(platform.claude.com)에 가입하고 들어갑니다.
  2. Settings → Billing(결제)에서 크레딧을 삽니다.
  3. Settings → API keys에서 키 만들기 단추를 누릅니다.
  4. 키 이름(예: toonlens)을 넣습니다. 키 종류와 만료 기간을 고르라고 하면 기본값을 둡니다.
  5. 키를 복사합니다. 키는 이때 한 번만 보입니다.

Billing 화면에서 지출 한도를 볼 수 있습니다. 처음에는 작은 금액만 넣기를 권합니다.

OpenAI

키 받는 곳: platform.openai.com → API keys · 공식 안내: Developer quickstart

  1. OpenAI Platform(platform.openai.com)에 가입하고 들어갑니다. ChatGPT 구독과 API 요금은 따로입니다.
  2. API keys 화면에서 Create new secret key를 누릅니다.
  3. 이름을 넣고 만든 뒤 키를 복사합니다. 키는 이때 한 번만 보입니다.
  4. Billing 화면에서 크레딧을 넣습니다. 크레딧이 없으면 사용량 한도가 낮습니다.

DeepSeek

키 받는 곳: platform.deepseek.com → API keys · 공식 안내: DeepSeek API Docs

  1. DeepSeek Platform(platform.deepseek.com)에 가입하고 들어갑니다.
  2. Top up(충전) 화면에서 잔액을 충전합니다. 잔액이 없으면 요청이 실패합니다.
  3. API keys 화면에서 Create new API key를 누릅니다.
  4. 이름을 넣고 만든 뒤 키를 복사합니다.

DeepSeek 서버는 중국에 있습니다. 툰렌즈 "클라우드 연결" 창의 안내를 읽고 고르세요.

DeepL

키 받는 곳: deepl.com/your-account/keys · 공식 안내: DeepL API 시작하기

  1. DeepL API 요금제 페이지(deepl.com/pro-api)에서 DeepL API Free 또는 Pro를 골라 가입합니다.
  2. 이미 DeepL 번역기(Translator) 계정이 있으면 로그아웃한 뒤 API용 새 계정을 만듭니다. DeepL 공식 안내가 이렇게 하라고 합니다.
  3. 계정의 API 키 화면(your-account/keys)에서 키를 복사합니다.

Free 키는 끝이 ":fx"입니다. 툰렌즈는 이것을 보고 Free 주소(api-free.deepl.com)로 보냅니다.

Google Cloud (번역 전용 · 클라우드 OCR)

키 받는 곳: console.cloud.google.com → API 및 서비스 → 사용자 인증 정보 · 공식 안내: API 키 관리

  1. Google Cloud 콘솔(console.cloud.google.com)에 들어가 프로젝트를 만듭니다.
  2. 결제 계정을 연결합니다.
  3. API 및 서비스 → 라이브러리에서 쓸 API를 사용 설정합니다. API를 먼저 켜야 키 제한에서 고를 수 있습니다.
    • 번역 전용(3단계): Cloud Translation API
    • 4단계 클라우드 OCR: Cloud Vision API
  4. API 및 서비스 → 사용자 인증 정보에서 사용자 인증 정보 만들기 → API 키를 누릅니다.
  5. API 제한(API restrictions)에서 위에서 켠 API만 고르고 저장합니다.
  6. "API 키 생성됨" 창의 키를 복사합니다.

Gemini 키(AI Studio)와 Google Cloud 키는 다를 수 있습니다. 번역 전용 키는 "클라우드 연결" 창에서 "Google Cloud Translation"을 고르고 넣습니다. 클라우드 OCR 키는 설정 → "고급: 번역 서비스·API 키" → "Google Cloud Vision" 칸에 넣습니다.

Microsoft Translator

키 받는 곳: portal.azure.com → Translator 리소스 → 키 및 엔드포인트 · 공식 안내: Translator 리소스 만들기

  1. Azure 계정을 만들고 Azure 포털(portal.azure.com)에 들어갑니다.
  2. Translator 리소스 만들기를 엽니다.
  3. 구독, 리소스 그룹, 이름을 넣습니다. 지역(Region)은 Global을 고릅니다.
  4. 가격 책정 계층은 무료 등급(F0)을 고를 수 있습니다. 무료 등급은 구독마다 1개입니다.
  5. 검토 + 만들기 → 만들기를 누르고, 끝나면 리소스로 이동을 누릅니다.
  6. 왼쪽 "리소스 관리" → 키 및 엔드포인트에서 "키 1"을 복사합니다.

지역을 Global이 아닌 곳(예: koreacentral)으로 만들었으면, 툰렌즈 설정 → "고급: 번역 서비스·API 키"의 Microsoft 칸에 그 지역을 넣습니다.
