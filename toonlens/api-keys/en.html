How to get an API key for ToonLens

Last updated: 2026-11-01. The steps for each provider follow that provider's official documentation (checked on 2026-11-01). Provider screens and prices can change. Check prices on each provider's page.

Levels 3 and 4 (cloud AI) in ToonLens send requests directly to the provider with your own API key. The developer never receives your key or what you translate. Charges go to the account that created the key.

Keep your key private. Do not show it to anyone or send it by email, chat, or screenshot. A leaked key lets others spend money on your account. If you think a key leaked, delete it on the provider's page right away and create a new one.

Enter the key in ToonLens (same for every provider)

  1. Create a key on the provider's page and copy it (steps below).
  2. In ToonLens, open Settings (gear at the top right). Under "Translation mode" at the top, tap the Level 3 or Level 4 card (picture ①).
  1. In the "Connect to cloud" window, select the provider (picture ②).
  2. If you do not have a key yet, tap "How to get a key" (picture ③). This page opens at that provider's section.
  1. Scroll the window up. Long-press the "API key" field and paste the key (picture ④). The key shows as dots.
  2. You can keep the default model (first line) (picture ⑤).
  3. Read the data transfer notice, then tap Agree and use (picture ⑥). The button turns on after you enter a key.

The key is stored encrypted on your device. After you save it, the field does not show it again. To change the key, paste a new key in the same window.

Google Gemini

Get a key at: aistudio.google.com/apikey · Official guide: Gemini API keys

  1. Sign in to Google AI Studio (aistudio.google.com/apikey) with your Google account.
  2. The first time, accept the Terms of Service. This creates a default project.
  3. On the API Keys page, tap Create API key.
  4. If asked for a project, select the default project.
  5. Copy the new key.

Each key belongs to a Google Cloud project. For free usage and prices, see Google's Gemini API pricing page. Google can use content sent on the free tier to improve its services.

Anthropic Claude

Get a key at: platform.claude.com → Settings → API keys · Official guide: Get your Claude API key

  1. Sign up and sign in to the Claude Console (platform.claude.com).
  2. Buy credits in Settings → Billing.
  3. In Settings → API keys, tap the button to create a key.
  4. Enter a name (for example, toonlens). If asked for a key type and expiration, keep the defaults.
  5. Copy the key. It is shown only once.

The Billing page shows your spend limit. Start with a small amount.

OpenAI

Get a key at: platform.openai.com → API keys · Official guide: Developer quickstart

  1. Sign up and sign in to the OpenAI Platform (platform.openai.com). A ChatGPT subscription and API billing are separate.
  2. On the API keys page, tap Create new secret key.
  3. Enter a name, create the key, then copy it. It is shown only once.
  4. Add credits on the Billing page. Without credits, usage limits are low.

DeepSeek

Get a key at: platform.deepseek.com → API keys · Official guide: DeepSeek API Docs

  1. Sign up and sign in to the DeepSeek Platform (platform.deepseek.com).
  2. Add balance on the Top up page. Requests fail without balance.
  3. On the API keys page, tap Create new API key.
  4. Enter a name, create the key, then copy it.

DeepSeek servers are in China. Read the notice in the ToonLens "Connect to cloud" window before you choose it.

DeepL

Get a key at: deepl.com/your-account/keys · Official guide: DeepL API getting started

  1. On the DeepL API plans page (deepl.com/pro-api), choose DeepL API Free or Pro and sign up.
  2. If you already have a DeepL Translator account, sign out and create a new account for the API. DeepL's official guide says to do this.
  3. Copy the key on your account's API keys page (your-account/keys).

A Free key ends with ":fx". ToonLens detects this and uses the Free API address (api-free.deepl.com).

Google Cloud (translation API and cloud OCR)

Get a key at: console.cloud.google.com → APIs & Services → Credentials · Official guide: Manage API keys

  1. Open the Google Cloud console (console.cloud.google.com) and create a project.
  2. Link a billing account.
  3. In APIs & Services → Library, enable the APIs you need. You must enable an API before you can select it in key restrictions.
    • Translation API (level 3): Cloud Translation API
    • Level 4 cloud OCR: Cloud Vision API
  4. In APIs & Services → Credentials, tap Create credentials → API key.
  5. Under API restrictions, select only the APIs you enabled, then save.
  6. Copy the key in the "API key created" window.

A Gemini key (AI Studio) and a Google Cloud key can be different. Enter a translation API key in the "Connect to cloud" window after you select "Google Cloud Translation". Enter a cloud OCR key in Settings → "Advanced: translation services and API keys" → "Google Cloud Vision".

Microsoft Translator

Get a key at: portal.azure.com → Translator resource → Keys and Endpoint · Official guide: Create a Translator resource

  1. Create an Azure account and sign in to the Azure portal (portal.azure.com).
  2. Open Create a Translator resource.
  3. Enter the subscription, resource group, and name. Select Global as the region.
  4. You can select the free pricing tier (F0). Each subscription can have one free tier resource.
  5. Tap Review + Create → Create. When it finishes, tap Go to resource.
  6. In the left pane, under Resource Management, open Keys and Endpoint and copy "KEY 1".

If you created the resource in a region other than Global (for example, koreacentral), enter that region in ToonLens Settings → "Advanced: translation services and API keys" → Microsoft.
